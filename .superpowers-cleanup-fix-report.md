# Fix: fail loudly when ACADEMY_URL is unset

## Summary

Added a guard clause to each of the four portal auth redirect pages that throws
a clear `Error` when `process.env.ACADEMY_URL` is missing, instead of silently
redirecting to the literal path `undefined/<route>` on the same domain (which
previously 404'd with no indication of the real cause).

No other behavior was changed — this is a guard-clause addition only.

## Verification

- `npx tsc --noEmit` — clean, no output, exit 0.
